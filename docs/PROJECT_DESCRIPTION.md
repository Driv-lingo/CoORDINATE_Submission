# Project description (hackathon card)

**Title:** CoORDINATE — From chaos to coordinated action.

**Challenge:** Disaster Assistance Navigator

**First sentence:** CoORDINATE combines real-time disaster conditions, community needs, and
available capabilities to turn requests for help into safe, coordinated response missions.

## Short description (≈120 words)

CoORDINATE combines real-time disaster conditions, community needs, and available
capabilities to turn requests for help into safe, coordinated response missions. A resident
describes their situation in their own words; Azure AI Foundry identifies each separate need
and deterministic safety rules decide what happens to it. CoORDINATE gives immediate,
safety-first guidance, points to trusted Virginia services with their sources and eligibility,
prepares handoffs to emergency services, utilities, shelter coordinators or caseworkers — and,
only where community help is appropriate and the resident asks for it, forms a
capability-matched volunteer team. Every active mission is then continuously re-checked
against live weather alerts, traffic and road closures. A sparking power line is never
assigned to "whoever is closest".

## Differentiation (one line)

Other navigators tell people what to do next; CoORDINATE also picks the right resolution
path for each need — and, where community resources are that path, safely makes it happen.

## Built with

Next.js, TypeScript, Azure AI Foundry, Azure Maps, Azure Cosmos DB, Azure Web PubSub, Azure App
Service, Bicep, GitHub Actions.
